# DEVSPACE — Агрегатор IT-новостей

**DEVSPACE** — это современное React-приложение для чтения IT-статей из популярных источников (**Habr** и **Dev.to**) в одном интерфейсе. Проект выполнен с акцентом на высокую производительность, адаптивный дизайн и удобство пользователя.

## Основные возможности
* **Мультиисточниковость**: Переключение между русскоязычным (Habr) и англоязычным (Dev.to) контентом в один клик.
* **Умный поиск**: Мгновенная фильтрация статей по заголовкам и тегам.
* **Система закладок**: Сохранение интересных материалов в локальное хранилище (LocalStorage).
* **Встроенный Reader**: Чтение полного текста статьи в модальном окне без перехода на сторонние сайты.
* **Адаптивная сетка**: Идеальное отображение на любых устройствах благодаря CSS Grid.
* **Темная тема**: Стильный интерфейс в стиле GitHub/VS Code.

## Технологический стек
* **Frontend**: React 18, Vite.
* **State Management**: React Context API (для закладок и выбора источника).
* **Data Fetching**: TanStack Query (React Query) + Axios.
* **UI Library**: Material UI (MUI).
* **Icons**: Lucide-React.
* **API**: Habr RSS (через rss2json) & Dev.to API.

## Архитектура проекта
Проект построен по модульному принципу:
* **/src/components** — общие компоненты (Navbar и т.д.).
* **/src/context** — глобальное состояние приложения.
* **/src/pages** — основные экраны (Feed, Explore, Bookmarks).
* **/src/App.css** — кастомные стили и переменные темы.

Разработано в рамках учебного курса по React.
